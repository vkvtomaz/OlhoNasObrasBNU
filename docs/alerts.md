# Alertas explicáveis

Alertas organizam pontos para verificação. Não comprovam fraude, corrupção, ilegalidade ou culpa. Cada alerta contém regra, dados usados, explicação, severidade, limitações e ação recomendada. Termos preferidos: “necessita esclarecimento”, “documentação não localizada” e “possível inconsistência entre fontes”.
